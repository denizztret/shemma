# DRW-111 Visual Fidelity v2 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) или superpowers:executing-plans для task-by-task execution. Steps used checkbox (`- [ ]`) syntax for tracking.

**Goal:** Расширить Miro export styling до full visual fidelity (12 colors / 4 sizes / 4 fonts / 9 arrowheads) + переключить frame export с Miro `frame` widget на `shape` rectangle + `group` widget для unlimited nesting.

**Architecture:** Аддитивные изменения в существующий `apps/backend/src/export/miro/` module: новые pure-function mapping helpers + wire в `build*Payload` функции + новый `buildShapeForFrame` для frame-as-shape + новый Pass C для `POST /v2/boards/{id}/groups` + расширение tracking schema (`groups?` field).

**Tech Stack:** Bun runtime + TypeScript, tldraw 5.x, Miro REST API v2 (POST /v2/boards/{id}/items/bulk, POST /v2/boards/{id}/connectors, POST /v2/boards/{id}/groups), bun test framework.

**Target release:** 0.22.0 (MINOR — change-of-default behavior на frame export + additive styling propagation).

**Spec:** [`docs/superpowers/specs/2026-05-22-drw-111-visual-fidelity-v2-design.md`](../specs/2026-05-22-drw-111-visual-fidelity-v2-design.md) (v0.3).

export function tldrawSizeToFontSize(size: string | undefined): string {
  switch (size) {
    case "s":  return "12";
    case "l":  return "20";
    case "xl": return "30";
    case "m":
    default:   return "14";
  }
}

export function tldrawSizeToBorderWidth(size: string | undefined): string {
  switch (size) {
    case "s":  return "1.0";
    case "l":  return "3.0";
    case "xl": return "4.0";
    case "m":
    default:   return "2.0";
  }
}

export function tldrawSizeToStrokeWidth(size: string | undefined): string {
  return tldrawSizeToBorderWidth(size);
}

export function tldrawSizeToStickyFontSize(size: string | undefined): string {

    case "s":  return "14";

/** Returns frames sorted outer-first → inner-last (depth-first). */
export function framesInDepthFirstOrder<T extends { id: string; parentId?: string }>(
  frames: T[],
): T[] {
  const byId = new Map(frames.map(f => [f.id, f]));
  const depth = (f: T): number => {
    let d = 0;
    let cur: T | undefined = f;
    while (cur?.parentId && byId.has(cur.parentId)) {
      d++;
      cur = byId.get(cur.parentId);
    }
    return d;
  };
  return [...frames].sort((a, b) => depth(a) - depth(b));
}
```

  rootId: string,
  store: Record<string, TLRecord>,
  selection: Set<string>,
): string[] {
  const out: string[] = [];
  for (const id of selection) {
    if (id === rootId) continue;
    const s = store[id];
    if (s?.parentId === rootId) out.push(id);
  }
  return out;
}
```

**Why direct children only:** Pass C iterates frames deepest-first. Inner frame's group already contains its leaf children. Outer frame's items list = [outer-rect, ...direct-children-miroIds-OR-inner-groupId]. Recursive walk would double-count.

- [ ] **Step 3: Implement Pass C orchestrator**

В `runMiroExport`, после Pass A2 + Pass B:

```ts
// Pass C — group widgets (DRW-111).
// Iterate deepest-first so inner groups exist when outer wraps them.
const groupMap = new Map<string, string>();
const sortedFramesShallow = framesInDepthFirstOrder(
  frames.map(id => ({ id, parentId: store[id]?.parentId as string | undefined }))
);
const framesByDepthDeepest = [...sortedFramesShallow].reverse();

const selectionSet = new Set([...frames, ...items]);

for (const f of framesByDepthDeepest) {
  const frameMiroId = frameMap.get(f.id);
  if (!frameMiroId) continue;

  // Direct children only; nested frames contribute their groupId, not leaves.
  const childElementIds = directChildrenOf(f.id, store, selectionSet);
  const childMiroOrGroupIds: string[] = [];
  for (const childId of childElementIds) {
    const childGroupId = groupMap.get(childId);   // child is a frame, already grouped
    if (childGroupId) {
      childMiroOrGroupIds.push(childGroupId);
      continue;
    }
    const childMiroId = itemMap.get(childId);     // child is a leaf shape/note/text
    if (childMiroId) childMiroOrGroupIds.push(childMiroId);
  }

  if (childMiroOrGroupIds.length === 0) continue;  // skip frames with no children — single-item group rejected per Phase 0 Task 0.1

  try {
    const resp = await p.client.createGroup(p.boardId, [frameMiroId, ...childMiroOrGroupIds]);
    groupMap.set(f.id, resp.id);
  } catch (e) {
    runError = `pass-c: ${(e as Error).message}`;
    break;
  }
}

if (groupMap.size > 0) {
  commitBoardGroupExport(p.room, {
    boardId: p.boardId,
    groupMappings: Array.from(groupMap, ([elementId, miroGroupId]) => ({ elementId, miroGroupId })),
  });
  p.onCommit?.(p.room);
}
```

**Flatten fallback** (если Phase 0 Task 0.1 step 3 показал nested groups rejected): replace `childMiroOrGroupIds` building с recursive descent через children, добавляя all leaf miroIds в один list per spec § 8.4.
